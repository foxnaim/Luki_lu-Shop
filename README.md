## About

A modern e-commerce online store with product browsing, shopping cart, and checkout functionality. Built with Next.js and TypeScript for a fast shopping experience.

## Features

- 🛍️ **Product Catalog** — Browse products with filters and search
- 🛒 **Shopping Cart** — Add items, manage quantities
- 💳 **Checkout** — Streamlined checkout process
- 📱 **Responsive** — Mobile-first design
- ⚡ **Fast** — Server-side rendering with Next.js
- 🎨 **Modern UI** — Styled with Tailwind CSS

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Framework | Next.js |
| Language | TypeScript |
| Styling | Tailwind CSS |

## Getting Started

```bash
git clone https://github.com/foxnaim/Luki_lu-Shop.git
cd Luki_lu-Shop
yarn install
yarn dev
```
